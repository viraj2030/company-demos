# Idea to production

A phone-first expert course from an idea to a live product using Grok Bots, Cursor cloud agents, Bugbot, GitHub, and Viraj's connectors. Live at https://viraj2030.github.io/company-demos/idea-to-production/. Open `index.html` in a browser (or serve this folder) to run it locally. Facts come from `docs/research.md` and `docs/research-v2.md`.
