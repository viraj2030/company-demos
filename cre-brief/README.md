# CRE broker brief (phone demo)

Static, phone-openable US CRE brief (financing squeeze + Class A / secondary) with public-source citations.

## Run locally

From the repo root:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/cre-brief/`.
